## v4.2 — 2026-08-08

### 고침

**멤버인데 "멤버가 아니에요" 가 뜨던 문제.** 서버 목록을 로그인할 때 한 번만 받아 두는데
로그인은 30일을 살아요. 그 사이에 서버에 새로 들어오면 다시 로그인하기 전까지 계속
비멤버로 막혔어요. 이제 목록에 없으면 **한 번 다시 받아 보고** 판단해요.

조회가 실패하면 기존 목록을 그대로 둬요. 실패를 "서버가 하나도 없음"으로 읽으면
멀쩡한 사람이 모든 서버에서 튕겨나요.

**원본 링크가 사운드클라우드에서 안 나오던 것.** 주소를 유튜브 ID로만 만들고 있었어요.

### 새로 들어간 것

- **원본에서 열기 ↗** — 재생 카드 제목 옆과 대기열 각 줄에. 우클릭 메뉴에만 있어서
  휴대폰에서는 사실상 없는 기능이었어요. 터치 기기에서는 버튼이 더 커져요.
- **개발자 콘솔** — 빈 배경 우클릭 → `⌨ 개발자 콘솔`. 기본은 숨김이에요.
  `Tab` 자동완성과 `↑↓` 기록이 되고, `now` 로 지금 싱크 상태를 바로 볼 수 있어요.
- **디스코드 명령어도 로그에 남아요** — `마참님이 디스코드에서 곡을 넘겼어요`.
  전에는 리모컨에서 한 것만 보여서 채널에서 `/스킵` 을 눌러도 이유 없이 곡이 바뀐 것처럼 보였어요.

### 손본 것

- **자동재생 버튼** — 켜짐 판정이 두 군데에서 서로 달라서, 켜져 보이는 버튼을 눌러도
  아무 일이 안 나고 "켰어요" 만 뜨던 게 고쳐졌어요. 아이콘도 상태에 따라 바뀌어요.
- **긴 누르기 메뉴** — iOS 에서 글자 선택 말풍선이 메뉴를 덮던 걸 막았어요. 짧은 진동도 와요.
- **같은 가수 쿨다운 `0`** — `무제한` 이라고 적혀 있어서 반대로 읽혔어요. `끔` 으로 고쳤어요.

## v4.0 — 2026-08-08

봇을 저 혼자 쓰는 게 아니게 되면서, 서버 하나를 전제로 만든 것들을 전부 서버별로 갈랐어요.

### 서버 승인

**아무나 초대해도 바로 못 써요.** 초대 자체는 Discord 쪽이라 막을 수 없어서, 대신 쓰는 걸 막아요.
새 서버는 승인 대기로 들어오고, 봇 주인이 승인해야 명령어와 리모컨이 열려요.

한 번 차단한 서버는 **다시 초대해도 안 풀려요.** 안 그러면 내보냈다 부르는 것만으로 차단이 해제되니까요.

### 곡 알림 방식 (서버별)

곡이 바뀔 때 새 글을 올릴지, 카드 하나를 고칠지 고를 수 있어요. **기본은 갱신**이에요 —
곡마다 새 글을 쌓으면 세 시간 파티 뒤에 채널이 재생 카드 60장이 되거든요.
`안 보냄`도 있어요. 리모컨만 쓰는 서버용이에요.

### 아무도 없을 때 (서버별)

음성 채널에 봇만 남으면 `그대로 두기`(기본) / `재생만 멈추기` / `나가기` 중에 골라요.
대기 시간도 5초~1시간으로 정해요. 잠깐 나갔다 오는 사람 때문에 바로 끊기면 안 되니까요.

기본이 `그대로 두기`인 이유는, 아직 듣는 사람이 있는데 갑자기 나가는 쪽이 더 놀랍기 때문이에요.
봇 주인은 모든 서버에 같은 규칙을 **강제**할 수도 있어요.

### 차트를 진짜 차트로

인기·나라별·장르 차트가 곡이 아니라 **몇 시간짜리 모음 영상**을 물어 오고 있었어요.
YouTube Music이 매일 갱신하는 차트 재생목록으로 바꿨고, **27장 전부 곡 수와 길이를 직접 확인**했어요.

노래방은 **TJ 공식 차트를 직접 가져와요.** 유튜브 검색으로 흉내내던 걸 진짜 순위로 바꿨어요.
발라드·댄스·트로트·인디·팝송·J-POP + 전체 인기 100.

**트는 건 반주(MR)가 아니라 원곡(AR)이에요.** 노래방 순위만 빌려오고 곡은 원곡을 틀어요.

한 가지 더 — TJ 트로트 1위가 **86분짜리 `임영웅메들리`**였어요. 그대로 담으면 대기열 한 칸이
한 시간 넘게 잠겨서, 이제 15분 넘는 항목은 차트에서 빼요.

### 웹에서 듣기

- **사운드클라우드도 들려요.** 전에는 안내문만 뜨고 무음이었어요.
- **싱크를 직접 맞춰요.** `⏱ 싱크(나만)`에서 0.5초씩 ±10초까지. 계정에 저장돼서 다른 기기에서도 그대로예요.

### 그 밖에

- **재생 중인 곡에도 좋아요·슈퍼·싫어요** — 곡이 시작하는 순간 버튼이 사라지던 게 고쳐졌어요.
- **🧺 추천 바구니** — 자동 재생이 뭘 근거로 고르는지 보여주고, 각각 비울 수 있어요.
- **듣는중·보는중을 누르면 창이 떠요** — 전에는 옆 패널이 없는 배치에서 눌러도 아무 일이 없었어요.
- **로그인 없이도 지금 곡을 볼 수 있어요.** 곡 제목과 가수만 나와요 — 신청한 사람, 채팅, 멤버는 안 나가요.
- **패치노트** — 프로필 메뉴 📝, 새 버전이면 한 번 알려드려요.
- **권한이 없을 때 누가 할 수 있는지** 알려줘요.

### 고친 버그

셋 다 **재시작하면 기억이 날아가서** 생긴 같은 문제였어요.

| 증상 | 원인 |
|------|------|
| 권한이 있는데 "권한이 없어요" | 역할 정보가 메모리에만 있었어요. 재시작 직후 Discord가 응답을 미루면 "모른다"가 "역할 없음"으로 바뀌었어요 |
| 일시정지가 "CSRF 검증 실패" | 로그인은 살아나는데 보안 토큰만 새로 만들어져서 서로 안 맞았어요 |
| 곡 담기 "입력값을 확인해 주세요" | 브라우저 검색으로 찾은 곡에 주소가 빠져 있었어요 |

### 업데이트가 덜 끊겨요

전에는 그냥 강제 종료라 재생 위치도 안 남고 음성에 유령 연결이 남았어요.
이제는 **끊긴 지점을 기억했다가 다시 켜지면 같은 채널에서 이어서** 틀어요.
업데이트 중에는 오류 화면 대신 `🛠 곧 다시 연결돼요`가 떠요.

## v3.1 — 2026-08-07

### 고침

**패널형 배치를 되돌릴 수 있게 했어요.**
패널을 닫으면 다시 여는 방법이 사실상 안 보였어요. `＋` 버튼이 24px짜리 아이콘 하나였고
색도 화면에서 제일 흐린 단계였거든요. 이제 `＋ 창` 이라고 글자로 쓰고, **닫아둔 창 개수까지
같이 보여줘요.** 닫아둔 게 있으면 테두리로 강조도 해요.

**패널을 줄이면 안이 잘리던 것도 고쳤어요.** 이제 그 패널 안에서 스크롤해요.
모바일 관성 스크롤도 되고, 스크롤이 부모로 새지 않아요.
화면 아래에 긴 가로 스크롤바를 하나 두는 방식은 쓰기 번거로워서 안 골랐어요.

**마지막 남은 패널의 ✕ 는 미리 막았어요.** 전에는 눌러도 아무 일이 없었어요.
지금은 버튼이 비활성이고 `창이 하나뿐이라 닫을 수 없어요` 라고 이유를 알려줘요.

### 새로 들어간 것

- **배치 슬롯 5칸** — 마음에 드는 패널 배치를 저장해 두고 오갈 수 있어요. 계정에 저장돼요.
- **배치 공유 코드** — `MCM1…` 로 시작하는 코드를 복사해서 넘겨주면 상대가 그대로 써요.
  서버를 안 거쳐요. 받은 코드는 반드시 검사를 거쳐서 적용해요.
- **기본으로 되돌리기** — 배치가 꼬였을 때 한 번에 원상복구.
- **차트 곡 수 설정** — 10~100곡. 관리 콘솔에서 서버마다 정해요.
- **노래방 차트 4장 추가** — TJ 힙합 · TJ J-Pop · TJ 팝송 · TJ 록·밴드.

### 차트가 안 되던 문제

`한국 인기곡` 과 `전세계 인기곡` 이 비어 있었어요. 확인해 보니 **재생목록 주소가 죽어서**
실제로 0곡이 나오고 있었어요. 검색 방식으로 바꿔서 50곡이 안정적으로 나와요.
**이미 돌아가고 있던 서버의 DB도 자동으로 고쳐요**(스키마 v14). 단, 관리자가 직접 바꾼
주소는 건드리지 않아요.

관리 콘솔의 차트 관리에 **주소 3가지 방식 설명**을 넣었어요.

| 방식 | 성격 |
|------|------|
| `ytsearch50:검색어` | 안 죽어요. 기본값. 숫자는 위 설정으로 자동 변경돼요 |
| `https://…playlist?list=…` | 정확하지만 **ID가 자주 바뀌어요.** 넣고 나서 곡 수를 확인하세요 |
| `internal:…` | 우리가 실제로 튼 기록으로 만드는 차트 |

차트는 **6시간 캐시**예요. 여러 명이 같은 차트를 눌러도 실제 조회는 한 번만 돌아요.
바로 새로 받고 싶으면 각 줄의 `↻` 를 누르세요.

### 로그

설정을 바꾸면 사람이 보는 피드에 **JSON 덩어리가 통째로** 나가고 있었어요.

```
전 ▸ 마참 님이 limits 을 {"guildId":497…,"minVolume":0,…} → {…} 로 바꿨어요
후 ▸ 마참님이 **서버 대기열 수** 을 100 → 991 로 바꿨어요
```

이제 **실제로 달라진 항목만** 짚어요. 여러 개면 `설정 3개를 바꿨어요 (최대 볼륨, 서버 대기열 수, 웹 채팅)`.
값도 한국어로 옮겨요 — `0` 은 `무제한`, 참/거짓은 `켬`/`끔`, 권한은 `같은 음성 채널` 처럼요.

## v3.0 — 2026-08-07

한 판에 45가지가 들어갔어요. 크게만 적을게요.

### 보는 방식

- **배치 6종** — 3단(기본) · 2단 · 집중 · DJ · 수다 · **패널(도킹)**
  패널형은 토스증권/유니티 에디터처럼 창을 쪼개고 붙이고 탭으로 겹칠 수 있어요.
- **테마 7종** — 다크(기본) · 라이트 · 미드나잇 · 그레이 · 노르드 · 베이지 · 레트로
  \+ 시스템 설정 따라가기.
- 배치와 테마 모두 **계정에 저장**돼요. 처음 들어오면 배치 고르는 창이 떠요.
- **너비·높이 마우스로 조절** 가능하고, 배치가 달라도 **기능은 전부 똑같아요.**

### 대기열

- **정렬 3종** — 점수제 · 시간제 · 공평제. 각각 설명이 붙어요.
- **5초마다 재정렬**(500곡 넘으면 15초). **다음 정렬까지 남은 초를 카운트다운**으로 보여줘요.
- 대기열이 길어지면 **점수 계산 근거**와 **누가 좋아요/슈퍼 좋아요를 눌렀는지** 보여줘요.
- 좋아요 · 싫어요 · 슈퍼 좋아요 · 대기 가점 **점수를 각각 설정**할 수 있어요.
- **붐따** 켜고 끄기, 기준 수, 동작(맨 뒤로/빼기) 설정.
  붐따는 **대기열에만** 걸려요. 지금 나오는 곡은 안 건드려요. 항상 로그와 알림이 남아서
  곡이 조용히 사라지는 일이 없어요.
- **투표 스킵** — 지금 듣고 있는 사람 기준 / 리모컨 접속자 기준 중에 골라요. 비율과 최소 인원 설정.
- **슈퍼 좋아요 쿨타임과 하루 횟수 제한.**
- 1인 대기열 · 서버 대기열 상한을 크게 늘렸고, **횟수·시간·곡수는 전부 `무제한`으로 둘 수 있어요.**

### 듣기

- **웹에서도 들을 수 있어요.** 토글이고, 소리 설정은 디스코드와 따로 놀아요.
  서버가 소리를 중계하지 않아서 **서버 부담은 0**이에요.
- **다음 예정곡**을 재생 카드에 같이 보여줘요. 자동재생이면 **다음 추천곡**을 미리 보여줘요.

### 자동재생

- **방식 3종** — 기준 곡(1~10개) / 최근 N곡 / 장르.
- **정책 4종** — 다양성 · 취향 따라가기 · 새로움 · 안정.
- 같은 아티스트 쿨다운, 최근 재생 회피 시간까지 조절돼요.
- **일반 유저도 켜고 끌 권한을 줄 수 있어요.**

### 차트

- 유튜브 뮤직(한국/전세계/J-Pop/힙합 등) · 사운드클라우드 · 노래방 차트.
- **우리 차트** — 이 서버, 그리고 봇 전체의 재생 횟수 차트. 좋아요 차트도 있어요.
  **자동재생으로 나간 곡은 따로 세서 차트에서 빼요.** 슈퍼 좋아요 가중치도 설정돼요.

### 재생목록

- **개인 재생목록**과 서버 재생목록이 따로 있어요.
- **한 번에 담기는 권한으로 뺐어요.** 상한도 설정돼요.

### 소통

- 채팅에 **반응(이모지)** · **@멘션** · **#노래태그** · **인용 답장**(디코/카톡처럼).
- **제안**은 탭이 아니라 별도 버튼 → 모달이에요.
- **활동 로그**는 사람이 읽는 문장이에요 — `ㅇㅇ님이 곡을 추가했어요`.
  필터가 있고, 기본 필터는 적당히 잡혀 있어요.
  **여러 곡을 한 번에 넣으면 한 줄로 묶이고**, 눌러서 펼쳐요. 시스템 로그는 안 묶어요.
- **우클릭 메뉴** — 곡·사람·대기열마다 쓸 만한 항목이 떠요.
  `Ctrl`/`Alt`/`Shift` + 우클릭이면 브라우저 기본 메뉴가 나와요.
- **사람 이름을 좌클릭**하면 그 사람 카드가 떠요. 최근 신청곡과 활동을 볼 수 있어요.

### 권한

- **등급 4단** — 봇 주인 / 서버 관리자 / 멤버 / 읽기 전용.
- **권한 10종을 따로따로** 정해요 — 검색·신청, 좋아요, 채팅, 재생·일시정지, 스킵,
  위치 이동, 볼륨, 대기열 편집, 자동재생 설정, 한 번에 담기.
- **권한마다 지정 역할을 따로** 줄 수 있어요. 통짜가 아니에요.
- **내 권한이 뭔지 화면에서 보여줘요.** 없는 기능은 **왜 없는지, 누구한테 있는지**까지 알려줘요.
- 그 서버에 없는 사람은 못 들어와요. 어떻게 들어와도 **읽기 전용**이고 아무것도 안 눌려요.

### 그 밖에

- **개인 통계** — 내가 넣은 곡, 재생 횟수, 좋아요/슈퍼 좋아요, 붐따, 비율,
  제일 많이 좋아요한 곡, 제일 많이 신청한 곡.
- **서버 블랙리스트**를 리모컨에서 봐요.
- **브라우저에서 직접 검색**해요(운영 패널에 YouTube API 키를 넣으면).
- 음성 채널 **듣는 중** 표시는 **봇과 같은 채널에 있을 때만** 나와요.
  봇이 서버에 있는지, 음성 채널에 들어가 있는지도 보여줘요.
- **알림을 끌 수 있어요.**
- **툴팁**을 전 화면에 달았어요.
- 말투를 `~해요` 로 바꿨어요. 정보를 해치지 않는 선에서만요.

### 안 넣은 것

- **시간대별 규칙**(업무시간 볼륨 제한, 자정 자동 종료) — 이건 오프라인 기기 얘기지
  리모컨 얘기가 아니에요.
- **귓속말** — 대신 인용 답장을 넣었어요.
- **비주얼라이저는 장식**이에요. 브라우저에 실제 소리 스트림이 없어서 진짜 스펙트럼은 못 그려요.
